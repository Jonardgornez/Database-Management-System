# Database Management Systems (DBMS) with MySQL

Welcome to the **Database Management Systems (DBMS) with MySQL** course repository.

This repository contains the lessons, examples, laboratory activities, exercises, and other learning materials for a **two-semester Database Management Systems course**. The folders are organized by week to make it easier to follow the course step by step.

---

## 📚 Course Overview

This course introduces the fundamental concepts of databases and teaches how to design, create, manage, and query relational databases using **MySQL**.

Throughout the course, you will learn how to:

- Understand what databases and DBMS are
- Design relational databases
- Create and manage tables
- Write SQL queries
- Perform CRUD operations
- Filter and sort data
- Use SQL functions
- Work with aggregate functions
- Create relationships between tables
- Use different types of JOINs
- Design ER diagrams
- Apply database normalization
- Use database constraints
- Manage transactions
- Create views and indexes
- Build a complete database project

# 🎯 Learning Goals

By the end of this course, students should be able to:

1. Explain the basic concepts of databases and DBMS.
2. Create and manage relational databases using MySQL.
3. Design tables using appropriate fields and data types.
4. Apply primary keys and foreign keys.
5. Perform CRUD operations using SQL.
6. Write queries to filter, sort, and analyze data.
7. Use SQL functions and aggregate functions.
8. Create and work with relationships between tables.
9. Use different types of SQL JOINs.
10. Design databases using ER diagrams.
11. Apply database normalization principles.
12. Use constraints to maintain data integrity.
13. Manage transactions using `COMMIT`, `ROLLBACK`, and `SAVEPOINT`.
14. Create views and indexes.
15. Develop a functional database project.

# 📖 How to Use This Repository

Follow the folders in order, starting from **Week 1**.

Each week builds on the concepts learned in the previous weeks, so it is recommended to complete the lessons and laboratory activities sequentially.

```text
Week 01
   ↓
Week 02
   ↓
Week 03
   ↓
Week 04
   ↓
   ...
   ↓
Week 15
   ↓
Week 16
```

For each week:

1. Read the lesson materials.
2. Study the SQL examples.
3. Practice the queries.
4. Complete the laboratory activities.
5. Review the concepts before moving to the next week.

# 👨‍💻 Practice Makes Progress

The best way to learn SQL and database management is through practice.

Don't just read the SQL examples. **Write the queries yourself, experiment with them, make mistakes, and learn how to fix them.**

> **Learn → Practice → Build → Improve**
